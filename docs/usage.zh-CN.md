# 桌面日程使用说明

[项目首页](../README.md) · [English](usage.en.md)

## 开始使用

1. [下载](../README.md#下载)适合你的 Windows x64 ZIP。本地版适合离线使用，完整版额外支持飞书同步。
2. 把 ZIP 完整解压到一个可写目录，再双击 `DesktopPlanner.exe`。保留程序旁的配置文件和 DLL。
3. 点「添加」或按 `Ctrl+N` 写下第一件事。点圆圈完成任务，用铅笔编辑，用垃圾桶删除。

支持 Windows 10 1903 及更新版本和 Windows 11。程序使用 .NET Framework 4.8 或 4.8.1。可在「高级设置 → 常规」修改语言和新建任务快捷键。

## 日计划、周计划和贴边

- 点日期两侧箭头切换日期，点日期打开日历。点「周计划」切换到本周，按周一至星期天分组。
- 拖动任务可重新排序。把日任务卡片拖过清单左侧或右侧可切换日期，移回清单后在想要的位置松手。按 `Esc` 取消拖动。
- 今天的清单为空且昨天有未完成任务时，点「接续前一天」即可把它们加入今天。昨天的记录仍可回看。
- 拖动标题栏移动窗口。未置顶时，鼠标离开后窗口会贴到最近的边，悬停边缘条即可展开。图钉用于置顶，叉按钮把窗口隐藏到托盘，托盘右键菜单可退出程序。

## 回顾、导出和备份

- 「总览」支持近 7 天、按周、按月和全部四种统计范围。「任务回顾」按日期显示任务，「查看全部」可连续浏览历史。
- 在「高级设置 → 数据 → 导出日程」选择全部、本周或本月，再选 Markdown 或 Word。导出使用当前工作区的本机记录。
- 日计划、周计划和历史格言保存在程序旁的 `Data\planner.json`，飞书缓存及待同步改动保存在 `Data\sync.json`。移动程序、切换发行版或备份时，先退出应用，再一并保留 `Data` 文件夹。
- 语言、主题、快捷键和飞书授权保存在 `%LOCALAPPDATA%\DesktopPlanner`。同一台电脑、同一个 Windows 账号下，换解压目录仍能读取这些设置。应用内更新入口在「高级设置 → 常规 → 关于与更新」。

## 飞书同步

1. 在完整版打开「高级设置 → 数据」，粘贴有编辑权限的飞书新版文档或知识库链接。建议新建一份文档专门放日程。
2. 点「连接飞书」。应用先尝试已有授权，首次连接或凭证失效时会打开浏览器。文档没有编辑权限时，到飞书的「分享」设置核对当前账号权限。
3. 连接成功后，可在应用或飞书里编辑任务。应用按自然周组织文档，每天用 `YYYY-MM-DD` 作标题，任务使用普通编号段落，例如 `1、整理本周计划`。

任务颜色会同步到飞书的任务编号底色。同一份文档在更新后的完整版上会显示相同的任务分类。

本地工作区和飞书工作区各自保存。在另一台 Windows 电脑上连接并授权同一份飞书文档，可以看到同一份计划。手机可直接在飞书查看该文档。

更换文档时，应用会先核对新链接和账号权限。有效凭证可以继续使用。刷新凭证失效或被撤销时，可在数据页点「重新授权」。[飞书官方 CLI](https://github.com/larksuite/cli)
