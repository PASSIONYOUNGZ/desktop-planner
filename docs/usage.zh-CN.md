# 桌面日程

## 开始使用

把 ZIP 完整解压到 `DesktopPlanner` 等目录，双击 `DesktopPlanner.exe`。首次运行会创建当前语言的桌面快捷方式，中文显示「桌面日程」，英文显示「Desktop Planner」。桌面日程可以离线使用，本地功能无需 Codex 或飞书账号。两版适用于 Windows 10 1903 及更新版本、Windows 11（x64），使用系统自带的 .NET Framework 4.8 / 4.8.1，无需另装 .NET 10。请完整解压，保留 exe 旁的 DLL 和 config 文件。较早或精简过的 Windows 可能需要先安装 .NET Framework 4.8。

- 点击「添加」或在组件内按 Ctrl+N 写任务，点击圆圈勾选，铅笔可修改正文。序号按位置自动生成，正文里的数字照常保留。拖动任务文字可以重新排序。日任务可以连续跨天移动，飞书同步在后台处理，不必等前一次写入完成。尚未开始发送的往返移动会合并，已经发送的移动先安全收尾。按住日任务，将浮起的卡片拖过列表左侧或右侧边界，即可切换日期，鼠标不必碰到边缘。卡片持续停在边界外时，每 0.75 秒继续翻一天；左右两边规则相同，可以直接换方向，连续跨多天。把卡片移回列表就停止翻页，可以上下排序，在目标位置松手完成移动，回手不会反向翻页，按 Esc 取消。
- 点任务行右侧、铅笔旁的垃圾桶即可移除该条。删除与勾选完成是两项独立操作。
- 点击日期两边切换前后一天，也可点击日期打开日历，或在标题区左右拖动。编辑时用 Enter 保存，Esc 取消。新建任务的组合键可在「高级设置 → 常规 → 新建任务快捷键」修改。
- 「高级设置 → 个性化」可切换配色，也可输入自定义的六位颜色值。默认使用雾蓝，主题随本机设置保存。
- 新用户首次运行时，中文 Windows 使用简体中文，其余 Windows 显示语言使用英文。已有安装升级后沿用中文。可在「高级设置 → 常规 → 语言」随时切换，选择保存在本机。
- 每日格言默认随机轮换。可在「高级设置 → 个性化 → 每日格言」改为固定格言或自定义格言库。格言库每行填写一句。随机轮换会避开过去七天显示过的格言，自定义句库里没有可用的新句时，从内置格言补足。固定格言每天显示所选句子，已记录的格言按当天原句回看，未来日期留空。
- 今天的清单为空且昨天有未完成任务时，可以在空清单说明下点「接续前一天」。前一天原记录保留。
- 在「总览」切换近 7 天、按周、按月或全部。左右箭头分别翻动七天、自然周或自然月。「全部」按月汇总。同页下方的「任务回顾」按日期从新到旧展示只读任务，可以滚动浏览，也可以点击有数据的柱子定位。点「查看全部」可在独立页面连续浏览所有历史任务，按 Esc 或点「返回总览」可返回。
- 在「高级设置 → 数据」找到「导出日程」，选择全部、本周或本月和 Markdown 或 Word 格式，再点「导出日程」保存。离线时也可以导出。
- 在「高级设置 → 常规 → 关于与更新」点「检查更新」。有新版时点「下载并安装」，应用会从 CNB 下载当前版本类型对应的 ZIP，校验后安装并重启。
- 窗口默认吸附在顶边偏左。拖动标题栏后，松手会停在原位。未置顶时，鼠标离开约 1 秒后会贴到当前屏幕最近的边并收成半透明窄条。鼠标移到边缘条上，停留约 0.35 秒即可展开。右上角的图钉切换置顶，置顶时面板保持展开。左键托盘图标显示窗口，右键可选择「显示窗口」「隐藏到托盘」或「退出桌面日程」。隐藏到托盘时程序继续运行，屏幕边缘不显示窄条。切到其他应用时，即使正在编辑任务，也会在离开约一秒后收起，未保存的草稿仍保留；再次展开可接着写。系统最小化或非主动隐藏会恢复为边缘条，主动隐藏到托盘不会自动弹出。高级设置中的「开机自启」默认开启，Windows 登录后会直接在顶边偏左显示边缘条。

## 周计划

点击任务清单旁的“周计划”切换，左右箭头按周翻页，再点“日计划”返回。以周一至星期天为一周，周任务与每天的任务分别保存，支持新增、编辑、勾选、删除和拖动排序。导出会包含所选范围内的周计划与日计划，总览的每日完成率只统计日任务，不把周目标重复计入。

关联飞书后，周计划同样使用后台队列和本机缓存。已有短日期日报继续识别，应用不批量搬移或改写原有章节；如已有周/日章节的顺序混乱，新增结构会停止并保留本地改动，需要先在文档核对顺序。重复周标题或日期标题不会猜测选取。

## 分发包选择

- **本地版 ZIP** 保留日计划、周计划、总览、格言、主题、贴边和导出，不包含飞书 CLI，不显示飞书连接入口，不进行飞书同步。使用 Windows 的 .NET Framework 4.8 / 4.8.1，解压即用。
- **完整版 ZIP** 在本地版功能之上增加可选的飞书同步，内含飞书 CLI，使用 Windows 的 .NET Framework 4.8 / 4.8.1，解压即用。

两版使用相同的数据格式，同一时间运行一个版本。换用另一个版本时，先退出应用，再把旧程序旁的 `Data` 复制到新程序旁。用过完整版再打开本地版时，只展示本地工作区。飞书工作区和本地清单各自保存。

中文界面显示「桌面日程」，英文界面显示「Desktop Planner」。用户输入的任务和已记录的格言保留原文。

## 飞书工作区，可跳过

1. 建议在飞书创建一份有编辑权限的空白新版文档，把它专门用于日程同步。
2. 打开「高级设置 → 数据 → 飞书连接」，粘贴自己有编辑权限的飞书 `docx` 或 `wiki` 链接，再点「连接飞书」或按 Enter。首次使用可能先在浏览器配置飞书应用，再授予文档读写权限。程序核对并读取文档成功后，设置页显示绿色对勾。
3. 首次添加任务时，应用会按自然周建立“周范围 → 周计划 → 每日计划”，每天使用 `YYYY-MM-DD` 日期标题，周计划在本周每天的内容之前，新日期按时间顺序插入。也识别有年份标题，或在「周范围 → 每日计划」下的 `11.4` 日期标题。任务写成 `1、任务` 这样的普通编号段落。孤立的 `11.4` 缺少年份时跳过。
4. 连接后，组件与文档自动双向同步。总览先读本机副本，后台逐批补齐可识别的日期。点「关闭连接」后可用已保存的地址重连或更换链接，本机工作区的任务单独保存。

连接后可在高级设置中直接「更换文档」或「重新授权」。应用会先核对新文档，旧文档有待同步改动时会保留它们并提示先处理。文档权限不足时，请在飞书的「分享」中为当前账号开通查看和编辑权限。需要授权时会自动打开默认浏览器，完成授权后返回应用即可。等待期间仍可重新授权、更换文档或关闭连接，这些操作会结束上一次等待；仅在无法打开浏览器时显示复制授权链接的备用入口。

分发包带可选的官方飞书 CLI。用户访问凭证有有效期，飞书工具会在 API 请求时检查访问凭证，在距离到期不足约 5 分钟时，用有效的刷新凭证自动续期。应用启动和恢复使用时会在后台检查连接，正常运行时也会继续检查，不必每次打开浏览器授权。设置页定期读取 CLI 保存的新到期时间，续期成功后显示的新时间以飞书返回值为准，并非固定每 7 天续期，也不保证每次启动都能延长相同天数。刷新凭证失效或被撤销时需要在浏览器重新授权。首次配置和修复应用密钥时，桌面日程会引导你在浏览器完成应用配置，并使用自己的本机配置目录。飞书账号和组织策略决定是否能创建应用并授权。

应用只在启用飞书工作区时调用飞书 CLI。首次连接由浏览器完成授权，之后通过飞书开放平台读写所选文档。本地工作区不需要这条连接，也不依赖 Codex。

多台 Windows 电脑可各自连接同一个飞书文档并完成授权。各设备的飞书工作区共享任务和完成状态，主题、格言、快捷键与本机工作区各自保存。已缓存日期的改动先显示在本机，再从队列写回。后台历史读取和排序前核对采用最多两路并行，待写入的任务优先处理。组件展开时约每 12 秒检查一次飞书，收起时约每 24 秒检查一次，激活时也会按需刷新。常规检查先读取文档版本号，有变动时才读取文档目录。编辑任务时暂停历史读取，优先发送当前改动。

日程、周计划和历史格言保存在程序旁的 `Data\planner.json`，飞书缓存和待处理队列保存在 `Data\sync.json`。移动程序时一并移动 `Data`。语言、主题等设置及飞书授权存放在 `%LOCALAPPDATA%\DesktopPlanner`。
